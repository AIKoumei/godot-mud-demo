[代码步骤]
# 1. 声明随机的全局种子，没有传入种子，使用随机数生成器随机取一个种子，所有方法的随机数都基于这个种子，每个步骤的随机数都基于全局种子，确保可重复生成相同结果。
# 2. 生成流程管线化，将每个步骤的输出作为下一个步骤的输入，确保每个步骤的独立性和可维护性。
# 2.1. 每个步骤都可以独立运行，也可以作为整体运行。
# 2.2. 每个步骤的输出都应是一个字典，包含该步骤生成的所有数据，确保数据的可传递性和可维护性。
# 2.3. 每个步骤的输入参数都应是一个字典，包含该步骤需要的所有数据，确保数据的可传递性和可维护性。
# 2.4. 每个步骤都可以单独输出像素图作为可视化结果，方便调试和理解生成过程，像素图最小尺寸为512*512。
# 3. 定义 MapGeneratorConfig 字典，包含所有生成参数（如城镇尺寸（SMALL/MEDIUM/LARGE）、形状（圆形 / 矩形）、随机种子等），确保可配置化。
  通过 gen_config() 生成随机配置（也支持自定义覆盖）
    根据尺寸配置， 随机生成对应范围的宽高（如小型城镇 12-16 格，中型城镇 16-22 格，大型 22-30 格）
    对于没有传入的配置字段，使用全局种子的随机生成器随机生成）
  当前支持的配置字段：
    size: "SMALL" | "MEDIUM" | "LARGE"
    shape: "CIRCLE" | "RECTANGLE"
    seed: int
# 4. 噪声使用 Simplex 噪声
# 5. 最终生成数据格式为
  {
    metadata:{
      version: "1.0.2",
      generated_at: "2023-12-31 12:00:00",
      config: {
        size: "SMALL",
        shape: "CIRCLE",
        seed: 0,
        ...
      }
      size: [12, 12],
    }
    data:{
      mask: ["x,y",...],
      edges: ["x,y",...],
      center: [64, 64],
      nodes: ["x,y",...],
      blocks: {
        "block_id":{
          size: [5, 5],
          position: [x, y],
          nodes: ["x,y",...],
        }
      },
      primary_road: ["x,y",...],
      secondary_roads: ["x,y",...],
      total_nodes: {
        "x,y":{
          type: "center",
          color: "#ff0000ff",
        }
      },
    }
  }
# 6. 所有生成文件都放到 output 目录下
# 7. 执行完毕后需要打印生成配置
# 8. 测试种子暂时遍历0-10
# 9. 所有的打印除了在控制台输出，还要在output.log文件中输出
#  生成城镇基础轮廓（Mask）
  根据配置的形状（圆形 / 矩形）和不规则度，结合 Simplex 噪声生成基础轮廓 Mask
  确定边缘点的时候：
    如果该点的九宫格内的节点都是有效节点，则该点不是边缘点
#  确定城镇中心
  优先选择轮廓的几何中心（宽高一半），若几何中心不在有效轮廓内，则选择离几何中心最近的有效坐标作为城镇中心。
#  生成主干道与城门
  从城镇中心向上下左右四个方向延伸主干道
  当主干道触及到轮廓边缘的时候：
    如果该轮廓后方有轮廓，则将该坐标作为主干道，并且将其从轮廓坐标中移除，然后将后方轮廓作为触及点继续检查
    如果该轮廓是该主干道方向上的最后一个轮廓，则将该坐标作为城门，并且将其从轮廓坐标中移除
      生成城门后，在城门垂直主干道的两个方向分别生成一个城门城墙，颜色为灰蓝色
      在创建城门城墙的时候，把城门城墙所在的位置节点也加入到edge和mask中
#  edge 后处理
  对偏移结束后的edge进行后处理：
    找一个符合条件的edge节点开始，并标记该节点为必要节点：九宫格内，横邻居为2或者竖领居为2的edge节点
    从该节点开始找横竖方向上的邻居，广度遍历所有edge，不要遍历mask节点
    如果当前节点为横竖邻居节点为3的节点：如果当前节点未标记，则标记为移除节点，如果邻居节点为未标记节点，也标记邻居节点为移除节点
    如果当前节点为横竖邻居节点为2，并且标记不为移除节点的节点：则将该节点以及横竖邻居标记都为必要节点，如果在标记邻居节点标记的时候，发现邻居标记为移除节点，则在标记对方为必要节点后，再将对方纳入待检查节点中，重新判断一次
    在遍历列表后，将非必要节点标记的节点从edge和mask中移除
##  在后处理后，对mask再进行一遍edge的检查，检查mask节点是否应该是edge节点
# 2. 进行edge合法性校对，如果edge不是首尾相连的，则打印错误信息
  只有合法性非法的时候才打印信息
  打印信息格式为："[ERROR] edge 合法性错误：{edge} 不是首尾相连的"
5. 将轮廓的最远边缘生成为城墙
  城墙有两个数据，一个是原始城墙，一个是所有城墙，所有城墙包含原始城墙和所有城门城墙
  生成城墙的时候：
    避开城门和城门城墙
    如果当前节点九空格内的节点都是有效节点，则当前节点不作为城墙节点
7. 生成区块（Blocks）与次级道路
  区块生成顺序：从中心开始，向上下左右四个方向生成区块，每次生成一个区块
    在生成block的时候，根据xy坐标距离center坐标的正负，归类为坐标轴上的1、2、3、4象限，对每一个象限的坐标都单独处理，
    在处理象限的时候，先把该象限内的坐标全部纳入 visited 的列表，然后计算距离（point.x-center.x,point.y-point.y），排序节点，距离最小的先处理，
    在以该节点为基础生成了一个block 后，将block范围内的节点标记为已访问，
  区块的生成避开主干道、次级道路、城墙、城门、城门城墙、其他已生成的区块
  区块大小：
    靠近中心的区块大小为5
    区块大小跟与中心的距离和主干道的距离有关，区块大小越远越小，直到减少到1
  生成一个区块后：
    如果该区块大小不为1，则在区块周边的空闲节点生成次级道路
    如果该区块大小为1，并且横竖方向上任意方向上都有次级道路，则该区块不生成周围的次级道路，
      否则，在该区块周边的空闲节点生成次级道路
  后处理：
    检查次级道路：
      如果该次级道路节点所在的次级道路不与其他任意道路连通，则将该道路上的所有节点从次级道路中移除，并将节点替换为大小为1的区块
  可视化：
    每个区块用一个随机颜色表示
    区块的中心写上区块的生成次序，从1开始，按生成顺序递增，字体大小为区块可视化大小的60%，颜色为区块颜色的补色
    区块的边缘用4px的反色边框高亮区块，边框需要在区块范围内，不能超出区块边界
8. 输出每个步骤的可视化结果
  每个步骤都可以输出一个像素图，展示该步骤的生成结果。
  像素图的尺寸最小为512*512，最大为1024*1024。
  每个像素的颜色表示该位置的状态（如轮廓、围墙、道路、区块等），颜色由 NODE_COLOR 定义。
  文件命名格式：
    每个步骤的可视化结果文件命名为：<seed>.step_<step_index>.<step_name>.png
    例如：0.step_0.mask.png 表示第0步生成的基础轮廓 Mask
