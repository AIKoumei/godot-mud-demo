##  水流侵蚀（适合生成山谷 / 河道）
    根据热度图执行水流侵蚀，在热度图值大于 0.5 的区域，才会执行水流侵蚀。
        对每个格子，找到 “坡度最陡的下坡方向”（水流方向）；
        让 “水流” 从高到低流动，沿途带走少量高度（降低水流路径的高度，形成山谷）；
        被带走的高度，堆积在水流的终点（比如平原 / 海洋边缘，形成冲积平原）；
        效果：原本平缓的山坡，被雕出 “V 型山谷”，山峰更突出，山谷更深邃，山脉特征明显；
        边缘也需要水流侵蚀
        模拟雨水落在地面后，顺着最陡的坡往下流，一路上带走泥土（侵蚀），到平缓处又堆积下来（沉积） 的过程，具体分 6 步，每一步都对应真实的自然规律：
    第一步：准备工作（给地形 “定规矩”）
        先有一张连续的高度图（比如用噪声生成的丘陵 / 山脉），所有地方的高度都用 0~1 表示（0 最低、1 最高）；
        设定几个 “自然规则”：
        只有坡度够陡（比如高度差超过 0.005），水才会流动（太缓的坡，水会渗进土里，不会形成水流）；
        水流每次能带走的泥土量（侵蚀量），和坡度陡缓相关 —— 坡越陡，水流越急，带走的泥土越多；
        水流带走的泥土，不会凭空消失，会在下游平缓的地方堆下来（沉积），坡越陡，沉积的泥土也越多；
        整个过程要重复很多次（比如 100 次），模拟长年累月的水流作用（一次侵蚀只像一场雨，多次才会形成山谷）。
    第二步：随机选地方 “下雨”（避免地形偏向）
        不会按固定顺序（比如从左到右、从上到下）处理地形，而是像随机下雨一样，每次都打乱处理顺序：
        先把地形里所有 “非边缘” 的格子（边缘是地图边界，不用管）混在一起；
        每次随机选一个格子，模拟 “雨水落在这个位置”，避免水流只往一个方向冲，让地形更自然。
    第三步：找 “水往哪流”（最陡下坡方向）
        对选中的这个格子（当前点），看它周围 8 个方向的邻居：
        对比当前点和每个邻居的高度，算出 “坡度”（当前点高度 - 邻居高度）；
        只挑 “下坡” 的方向（坡度为正，说明邻居更低），排除上坡 / 平坡；
        在所有下坡方向里，选坡度最陡的那个（水流会自然往最陡的地方流）；
        如果所有方向都是上坡 / 平坡，或者坡度太缓（低于 0.005），水就不流动，这一步结束。
    第四步：“水流冲泥土”（侵蚀上游）
        如果找到了最陡的下坡方向，就开始侵蚀当前点（水流的起点）：
        根据坡度陡缓，算这次要带走多少泥土 —— 坡越陡，带走的越多；
        从当前点的高度里，减去带走的泥土量（但保证高度不会低于 0，不会出现 “坑底低于海平面” 的情况）；
        这一步就像 “急流把山坡上的泥土冲下来”，当前点会变低，慢慢形成山谷的起点。
    第五步：“泥土堆下来”（沉积下游）
        水流把上游的泥土带到下游（最陡方向的邻居格子）：
        把刚才从上游带走的泥土，按比例堆到下游格子上（沉积量通常比侵蚀量少，因为部分泥土会被冲走）；
        保证下游格子的高度不会超过 1（不会堆成比山峰还高的土堆）；
        这一步就像 “河流到了平缓处，泥沙沉底”，下游会变高，形成冲积坡 / 河滩。
    第六步：重复循环（模拟长期作用）
        把第二步到第五步重复 100 次（或更多）：
        每一次循环，都是一场 “局部降雨”，只会雕刻一小片地形；
        多次循环后，无数次的小水流会慢慢把平缓的丘陵，雕出连续的山谷 / 河道 —— 陡的地方形成深谷，缓的地方形成浅沟，完全贴合自然地形的特征。
        结合 “热度图” 的定向侵蚀（自然语言补充）
        如果加上水流热度图（模拟 “哪里多雨、哪里干旱”），原理会多一步 “先看气候，再决定要不要冲”：
        先查当前格子的 “雨水热度”（0~1，0 = 极干旱，1 = 极多雨）；
        如果热度低于 0.5（干旱），直接跳过 —— 这里没水，不会有水流侵蚀；
        如果热度高于 0.5（湿润），热度越高，水流越急：
        多雨的地方（热度 1.0），水流带走的泥土是基础量的 2 倍，山谷会更深；
        稍湿润的地方（热度 0.6），水流带走的泥土只比基础量多一点，山谷更浅；
        最终效果：多雨的森林区会有密集的山谷 / 河道，干旱的沙漠区几乎没有水流侵蚀，只有光秃秃的裸岩。
    核心总结（一句话讲透）
        水流侵蚀的本质，就是模拟 “随机降雨→水找最陡下坡→急流冲蚀上游泥土→缓流沉积下游泥土” 的循环过程，重复多次后，平缓的丘陵会被雕出自然的山谷 / 河道；结合热度图后，还能让 “多雨区多山谷、干旱区少山谷”，更贴合真实的地理气候规律。
## 热侵蚀（适合生成陡峭悬崖）
    根据热度图执行热侵蚀，在热度图值大于 0.5 的区域，才会执行热侵蚀。
        遍历每个格子，计算其与相邻格子的高度差；
        如果高度差超过 “临界值”（比如 0.15），就把高处的部分 “坍塌” 到低处（比如高处降 0.05，低处升 0.05）；
        反之，如果高度差过小（比如 < 0.02），就轻微放大差值（比如高处升 0.01，低处降 0.01）；
        效果：消除 “缓坡丘陵”，强化 “陡坡 / 悬崖”，让地形要么平坦，要么陡峭，没有中间的圆润丘陵；
        边缘也需要热侵蚀
